## 3. Upload im Ads Manager (von Hand)

1. Ads Manager → Werbekonto 321782065041931 → Anzeigengruppe öffnen (siehe Tabelle oben) → **Anzeige erstellen**, oder die bestehende Anzeige N1 duplizieren. Beim Duplizieren bleiben Seite, Instagram-Konto und Sofortformular erhalten.
2. Anzeigenname aus der Tabelle eintragen.
3. Format **Einzelnes Bild oder Video** → Medien hinzufügen → **zuerst die 4:5-Datei** wählen.
4. Bei **Platzierungen** «Medien für jede Platzierung bearbeiten / anpassen» öffnen. Für **Stories und Reels** die 9:16-Datei hinterlegen, Feed behält 4:5.
5. Vorschaubild: Frame bei Sekunde 0–1 wählen (Hook-Text sichtbar).
6. Primärtext, Titel und Beschreibung aus Abschnitt 2 einfügen. Call-to-Action **«Angebot einholen»** und das bestehende **Sofortformular** wählen.
7. Musik: Meta **keine** zusätzliche Musik hinzufügen lassen (Option «Musik» aus). Der Ton ist eingebettet und lizenziert.
8. Advantage+-Creative-Optimierungen («Text verbessern», «Bild anpassen», «3D-Animation» usw.) **ausschalten**. Sonst verändert Meta Texte und Ausschnitte.
9. **Veröffentlichen, danach sofort auf «Aus» stellen** oder im Entwurf lassen. Aktivieren erst nach Freigabe.

### Meta-Richtlinien

- `_mit`-Varianten zeigen den Ausgangszustand nur in Sekunde 0–3, nie neben dem Ergebnis. Wird eine trotzdem abgelehnt, die passende `_ohne`-Variante verwenden.
- Die Texte sprechen keine persönlichen Merkmale an («Hast du …?»). Das bitte bei Anpassungen beibehalten.

## 6. Automatischer Upload (optional): Meta-Token

Damit Claude die Anzeigen selbst pausiert anlegen kann (`scripts/meta_upload.py`):

### Token erstellen (einmalig, ca. 15 Minuten)

1. **App anlegen**, falls im Business noch keine eigene App existiert: https://developers.facebook.com/apps → «App erstellen» → Anwendungsfall «Andere» → Typ **Business** → mit dem Business-Portfolio *Metamorphose* (130808084561726) verbinden. In der App das Produkt **Marketing API** hinzufügen.
2. **Systemnutzer anlegen:** https://business.facebook.com/settings → Nutzer → **Systemnutzer** → Hinzufügen → Name z. B. «Claude Upload», Rolle **Admin**.
3. **Assets zuweisen** (beim Systemnutzer → «Assets zuweisen»):
   - Werbekonto 321782065041931 → **Kampagnen verwalten**
   - Facebook-Seite Metamorphose → **Werbeanzeigen erstellen** und **Leads**
   - Instagram-Konto @steffivoelker.tattoo
   - die App aus Schritt 1
4. **Token generieren:** beim Systemnutzer → «Neuen Token generieren» → App wählen → Ablauf **Nie** → Berechtigungen:
   `ads_management`, `ads_read`, `business_management`, `pages_show_list`, `pages_read_engagement`, `pages_manage_ads`, `leads_retrieval`, `instagram_basic`
   → Token kopieren. Er wird nur einmal angezeigt.

### Variante ohne Unternehmensverifizierung: Nutzer-Token (60 Tage)

Systemnutzer-Tokens verlangen eine verifizierte Business-Verwaltung. Ein **Nutzer-Token** aus einer App im Entwicklungsmodus braucht das nicht, solange du selbst Admin des Werbekontos und der Seite bist.

1. https://developers.facebook.com/apps → «App erstellen» → Anwendungsfall «Andere» → Typ **Business**. Die App bleibt im **Entwicklungsmodus**, also ohne App-Review und ohne Unternehmensverifizierung.
2. https://developers.facebook.com/tools/explorer → oben rechts die neue App wählen → «User or Page»: **User Token** → Berechtigungen hinzufügen:
   `ads_management`, `ads_read`, `business_management`, `pages_show_list`, `pages_read_engagement`, `pages_manage_ads`, `leads_retrieval`, `instagram_basic`
   → **Generate Access Token** → mit deinem Facebook-Konto bestätigen.
3. Der Token gilt zunächst nur 1–2 Stunden. Verlängern: https://developers.facebook.com/tools/debug/accesstoken → Token einfügen → «Debug» → unten **«Extend Access Token»** → der neue Token gilt rund 60 Tage.
4. Den verlängerten Token wie oben als `META_ACCESS_TOKEN` in der Cloud-Umgebung hinterlegen.

### Token hinterlegen

- In Claude Code (claude.ai/code): in der Session-Titelleiste das **Umgebungsmenü** öffnen → **Edit**.
- Unter **Network secrets** (falls angeboten) oder **Environment variables** eintragen:
  `META_ACCESS_TOKEN=<Token>`
- Speichern und eine **neue Session** in dieser Umgebung starten. Laufende Sessions sehen den Token nicht.
- Den Token **nicht in den Chat** kopieren.
- Widerrufen jederzeit unter Business-Einstellungen → Systemnutzer → Token widerrufen.

### Ablauf danach

1. `npm run render:all`, falls die Videos in der neuen Session fehlen (ca. 40 Minuten).
2. `python3 -I scripts/meta_upload.py`: Probelauf. Zeigt die gefundene Vorlage N1 und die Anzeigengruppen.
3. `python3 -I scripts/meta_upload.py --apply`: Upload und 14 Anzeigen **pausiert** anlegen. Protokoll in `qa/meta_upload_log.json`.
